CARCASS — мод для Minecraft 1.20.1 (Forge 47.x), Java 17

ЯК ЗІБРАТИ .jar
1. Завантаж Forge MDK 1.20.1 (47.3.0) з files.minecraftforge.net -> "Mdk".
2. Розпакуй MDK в окрему папку. З неї потрібні лише файли:
      gradlew, gradlew.bat, gradle/wrapper/gradle-wrapper.jar
   Скопіюй їх у цю папку проєкту (поруч з build.gradle).
3. У цій папці відкрий термінал і виконай:
      gradlew build          (Windows)
      ./gradlew build        (Linux/Mac)
   Перший раз це довго (качає Forge) — це нормально.
4. Готовий мод: build/libs/carcass-1.0.0.jar
5. Поклади його в %appdata%\.minecraft\mods і запускай профіль Forge 1.20.1.

ЯК ГРАТИ
- Вбий тварину -> залишиться труп (замість викинутих предметів).
- Тримай ніж і затисни ПКМ на трупі -> розрізання, камера наближається.
- Рецепти ножів: палиця + крем'яний/залізний/золотий/алмазний предмет по діагоналі;
  незеритовий: алмазний ніж + незеритовий злиток + шаблон у кузні.
